🧹 PySpark Data Cleaning & Data Quality Workflow

This project demonstrates a concise, production-oriented PySpark data-cleaning workflow applied across multiple related datasets.
It focuses on building reliable, analysis-ready data through structured cleaning, validation, and transformation steps.

🔍 What’s Included

Column standardization

Date parsing & schema corrections

Null handling using conditional and median-based imputations

Outlier detection using IQR

Duplicate removal using composite keys

Enrichment through optimized joins

Window functions for grouped imputations

Clean Silver-layer datasets ready for analytics and modeling

🛠 Technologies Used

PySpark

Delta Lake

Databricks / Distributed Compute

Python 3.x

🎯 Purpose

To showcase practical, real-world data engineering techniques for cleaning, validating, and preparing raw datasets for downstream analytics, forecasting, or machine learning.
